# Призрак REEL Android
Package: ru.crystalgames.ghostreel

- Embedded Ghost Reel web UI with HTTPS-secure WebView origin.
- Camera permission restricted to the embedded app origin.
- Native Android gallery chooser, save to Movies/GhostReel and Pictures/GhostReel, share sheet.
- No advertising SDK or forced ads, no payments or AI API.
- Test builds use Android debug signing unless release keys are supplied as GitHub secrets.
- Video recording depends on Android WebView/MediaRecorder; current output format is WebM, not MP4.
