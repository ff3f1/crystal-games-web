ВЫБЕРИ СИТУАЦИЮ

Подсветка — предметы, которые можно двигать. Перемещай мышью или пальцем. В каждой попытке можно изменить только один объект. Не угадал? Сразу пробуй снова. Есть несколько способов спасти ситуацию.

Автономный тест без рекламы, аккаунтов и внешних библиотек. Сцены моделируются локально; физика упрощена специально для проверки идеи. Это ещё не финальная игра.
